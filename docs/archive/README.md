# Documentation archive

These records preserve superseded plans, status chronology, architecture detail and operational
evidence. They are not part of the normal agent reading path.

Read an archived file only to reconstruct a past decision or incident, verify retained evidence, or
understand a compatibility boundary that still affects current state. Current intent lives in
`AGENTS.md`, `PLAN.md`, `docs/STATUS.md`, `docs/ARCHITECTURE.md` and `PREPLAN.md`.
